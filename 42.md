# 42.sh

Stateful prime-scan / Gödel product TM. Env: `CMD=step|reconstruct`, `N` ticks, `LOG_TM_STATE` (default `state.json`).

At `t=3` the Gödel product lands on **G=42** (`E=[1,1,0,1]` over primes `(2,3,5,7)`).

## Run

```sh
rm -f state.json
LOG_TM_STATE=state.json CMD=step N=3 bash 42.sh
LOG_TM_STATE=state.json CMD=reconstruct N=1 bash 42.sh
curl -fsSL https://raw.githubusercontent.com/letsgo0226/42.sh/main/42.sh | bash
```

## Resident

- Daemon: `42_DAEMON.sh` (default **1s**; reconstruct every 3 steps)
- Actions: `.github/workflows/42.yml` (`*/5`)

## Bound

Formal consistency certificate only (`C` / `CSA` / `CG` / `CF`) — not a physical TOE or RH proof.
